# Ravenmoor Online

쿼터뷰(2.5D) 중세 웹 MMORPG. 성벽 안 마을은 안전 지대, 성문 밖은 몬스터와 PK가 있는 무법지대입니다.

- **서버가 모든 판정을 내립니다**: 이동 경로, 공격, 데미지, 사망, 보상은 서버가 계산하고 클라이언트는 "여기로 이동", "이 대상 공격", "대화" 같은 의도만 보냅니다. 클라이언트를 조작해도 데미지를 바꿀 수 없습니다.
- **실행에 필요한 외부 패키지가 없습니다**: Node.js 22.13 이상만 있으면 됩니다. WebSocket은 직접 구현했고, 데이터베이스는 Node에 내장된 SQLite(`data/ravenmoor.db`)를 씁니다.
- **그래픽은 3D 모델을 구운 스프라이트**입니다: CC0 3D 모델을 Three.js로 8방향 × 5동작(대기·걷기·공격·피격·사망)으로 렌더링해 `assets/sprites`에 넣어 두었습니다.

## 실행

```bash
npm start          # http://localhost:8080
npm test           # 봇으로 계정·PK·상점·전리품·의뢰·은행·보스·승급·파티·거래·길드·장터·칭호·습격·운영 명령까지 70개 항목 자동 테스트
npm run load       # 봇 40명으로 60초 부하 테스트 (틱 시간·메모리·트래픽 출력, PROF=1이면 CPU 프로파일 저장)
```

처음 접속하면 **새 캐릭터** 탭에서 이름·비밀번호·외형을 정해 가입합니다. 브라우저 탭 두 개(또는 시크릿 창)로 다른 캐릭터를 만들면 같은 맵에서 서로 보이고, 채팅과 PK를 할 수 있습니다.

## 지금 들어간 규칙

- **계정**: 이름 + 비밀번호(scrypt 해시) 로그인, 14일 유지되는 세션, 가입·로그인 시도 제한(IP당 5분 10회). 같은 계정으로 다른 곳에서 접속하면 이전 접속이 끊깁니다.
- **안전 지대와 PK**: 마을(성벽 안·성문)에서는 누구도 공격할 수 없고 몬스터도 못 들어옵니다. 성 밖에서 선량한 플레이어를 공격하면 1분간 보라색 이름, 죽이면 붉은 이름(카오틱). 카오틱은 죽을 때 금화 20%와 가방 속 아이템 하나를 바닥에 떨어뜨립니다. 예배당에서 헌금으로 속죄할 수 있습니다.
- **전리품**: 몬스터가 죽으면 금화와 아이템이 바닥에 떨어집니다. 처음 10초는 처치한 사람만 주울 수 있고, 2분 뒤 사라집니다.
- **아이템**: 무기 9종, 방어구·투구·방패·장화·장갑·반지, 물약, 귀환 주문서, 재료 4종(낡은 뼈·녹슨 철조각·저주받은 천·영혼석). 가방 36칸, 장비 7칸.
- **NPC**: 대장장이 로릭(무기 판매·제작·강화 +9까지, +4부터 실패 시 하락), 상인 베라(방어구·물약), 여관 주인 올가(휴식), 성문 경비병.
- **전직(레벨 10)**: 기사(기사단장 가웨인, 방패 강타·기절), 마법사(대마법사 이졸데, 원거리·화염구), 성직자(사제 안셀, 강화된 치유·신성한 빛), 도적(여관의 라스, 빠른 공격·급소 찌르기·출혈).
- **2차 전직(레벨 20)**: 같은 스승에게 승급. 팔라딘(신성 일격), 대마법사(번개 사슬), 주교(축복), 암살자(연속 찌르기). 두 번째 기술은 `D`.
- **보스 4종**: 회색 송곳니(남동쪽 강가, 울부짖어 졸개 소환·도약), 타락한 성기사(북동쪽 숲, 예고 후 내려찍기), 족장 크루쉬(북서쪽 야영지, 돌진·포효 기절), 리치 왕(남서쪽 늪, 내려찍기·소환·재생). 전용 장비를 떨어뜨리고 3~7분 뒤 다시 나타나며, 처치는 전체 공지됩니다.
- **의뢰 9종**: 경비병·상인·스승이 줍니다. 머리 위 `!`는 받을 수 있는 의뢰, `?`는 완료 보고. 토벌 수와 수집품은 서버가 셉니다.
- **은행**: 은행원 마르타에게 물건 48칸과 금화를 맡깁니다. 맡긴 것은 죽어도 잃지 않습니다.
- **밤낮**: 게임 하루는 실제 10분. 밤엔 플레이어·NPC·성문·우물 주변만 등불로 밝습니다. 시간은 서버가 정해 모두에게 같습니다.
- **채팅 명령**: `/귓 이름 내용`, `/파티 초대|수락|나가기|추방`, `/파티 내용`(파티 채팅), `/길드 …`, `/길 내용`(길드 채팅), `/거래 이름|수락|취소`, `/전체 내용`(10초에 한 번), `/도움`. 채팅 기록은 모두·주변·파티·길드·귓속말·알림 탭으로 걸러 볼 수 있습니다.
- **파티**: 최대 5명. 22칸 안에 있는 파티원이 경험치를 나눠 갖고(인원당 +10% 보너스), 토벌 의뢰도 같이 셉니다. 파티원끼리는 성 밖에서도 공격할 수 없습니다. 이름이 초록색으로 보입니다.
- **거래**: 서로 4칸 안에서 요청·수락. 각자 아이템 8칸과 금화를 올리고 둘 다 확인을 누르면 서버가 한 번에 교환합니다. 상대가 내용을 바꾸면 확인이 풀립니다.
- **운영**: 첫 번째로 가입한 계정이 관리자입니다(`ADMIN_NAMES=이름1,이름2` 환경변수로 지정 가능). 채팅에서 `/공지`, `/킥`, `/차단 이름 [10분|2시간|3일] [사유]`, `/차단해제`, `/텔레포트`, `/소환`, `/아이템`, `/금화`, `/레벨 수 [이름]`, `/접속자`, `/몬스터 종류`, `/습격`(성문 습격 즉시 시작), `/날씨 맑음|비|안개`를 쓰고, 화면 아래 "운영 페이지"에서 접속·차단 목록·최근 기록(로그인, PK, 거래, 차단, 길드, 장터, 습격)·백업 목록을 봅니다. DB는 30분마다 `data/backups/`에 자동 백업(최근 48개 보관)되고 운영 페이지에서 즉시 백업할 수 있습니다. `/health`는 접속자·몬스터·틱 시간·메모리를 JSON으로 돌려줍니다.
- **소리**: 외부 파일 없이 코드로 합성한 효과음(타격·치명타·전리품·레벨업·기술·보스)과 바람·분수·밤 귀뚜라미·6시간마다 종소리. 거리에 따라 작아집니다.
- **몬스터**: 해골 졸개 Lv2 · 산적 Lv4 · 해골 도적 Lv5 · 해골 전사 Lv9 · 탈영 기사 Lv11 · 해골 마법사 Lv13 · 이단 사제 Lv15 · 황야 광전사 Lv20. 마을에서 멀어질수록 강해집니다. 12마리 중 1마리는 **정예**(금색 이름, 체력 2.2배, 보상 3배, 강화 장비 드롭 확률).
- **길드**: `/길드 생성 이름`(10레벨, 금화 3,000) 또는 `G` 창에서 창설. 초대·수락·탈퇴·추방·부길드장·위임·공지·해산·순위, 길드 채팅 `/길 내용`. 길드원끼리는 공격할 수 없고 이름 위에 〔길드명〕이 보입니다. SQLite에 저장되어 재접속해도 유지됩니다.
- **장터**: 상인 베라의 "장터" 탭에서 가방 속 물건을 가격을 정해 올리고(한 번에 8개), 다른 모험가가 사면 수수료 5%를 뺀 금화가 판매자에게 갑니다(오프라인이면 저장된 캐릭터에 바로 입금).
- **매일 현상금**: 남문 경비병·기사단장·대마법사가 매일(KST 자정 초기화) 반복 의뢰를 줍니다. 정예 사냥 현상금도 있습니다.
- **성문 습격**: 25~40분마다 무작위 성문 밖에 해골 무리(10마리, 접속자 평균 레벨에 맞춤)가 나타납니다. 10분 안에 모두 물리치면 참가자 전원이 금화·경험치를 받습니다. 화면 위 주황 막대에 남은 수와 시간이 보입니다.
- **칭호**: 레벨·처치 수·보스·PK·습격 격퇴·의뢰 완주·재산으로 13종이 열리고, 캐릭터 창(`C`)에서 골라 이름 앞에 붙입니다.
- **회복과 보호**: 6초 동안 싸우지 않으면 체력·마나가 서서히 차고 마을 안에서는 두 배입니다. 6레벨 미만은 PK를 하지도 당하지도 않습니다. 파티원은 전리품 우선권을 같이 가집니다.
- **날씨**: 서버가 비·안개를 가끔 내립니다(모두에게 같음). 비는 소리와 함께, 안개는 플레이어 주변만 보입니다.
- **미니맵**: 성문 방향(N/E/S/W), 보스(주황 별), 정예(금색), 파티원(초록, 시야 밖도), 클릭한 목적지(X)를 표시합니다. 설정에서 크게 볼 수 있습니다.
- **처음 온 사람을 위한 도움말**: 이동·성 밖·낮은 체력·전리품·가방·파티·보스 상황마다 한 번씩 안내가 뜹니다(브라우저에 기억).
- 모든 판정(이동·공격·구매·제작·강화·전직)은 서버가 하고, NPC와의 거리도 서버가 확인합니다.

## 폴더 구조

```
server/   index.js(웹 서버·계정 API·운영 페이지)  ws.js(WebSocket)  db.js(SQLite·백업)  game.js(게임 규칙·틱·습격·날씨·칭호)  social.js(파티·거래·귓속말)  guild.js(길드)  market.js(장터)  admin.js(운영 명령·차단·기록)
shared/   world.js(맵·길찾기)  rules.js(아이템·상점·직업)  ← 서버와 클라이언트가 함께 씀
client/   index.html  style.css  main.js(렌더링·입력·HUD)  ui.js(가방·장비·상점 창)
assets/sprites/   구운 스프라이트 PNG + manifest.json
tools/bake/       3D 모델 → 스프라이트 굽기 도구
tools/test-multiplayer.mjs   자동 테스트
tools/load-test.mjs          부하 테스트
```

## 스프라이트 다시 굽기 / 새 모델 추가

```bash
npm run fetch-assets                      # CC0 원본 모델 + Three.js 받기
npm i -D playwright && npx playwright install chromium
npm run bake                              # 전부
npm run bake -- knight castle             # 일부만
```

`tools/bake/config.json`에 모델 파일, 크기, 동작 이름을 적으면 됩니다. glTF/GLB 형식을 지원합니다.

## 성능

`npm run load`로 봇 150명을 돌리면 틱당 약 10ms(예산 50ms), 메모리 약 170MB, 클라이언트당 약 10KB/s입니다. 스냅샷은 바뀐 것만 보내고(델타), 주변 검색은 공간 해시를 씁니다.
