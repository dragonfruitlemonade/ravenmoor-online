# Ravenmoor Online

쿼터뷰(2.5D) 중세 웹 MMORPG. 성벽 안 마을은 안전 지대, 성문 밖은 몬스터와 PK가 있는 무법지대입니다.

- **서버가 모든 판정을 내립니다**: 이동 경로, 공격, 데미지, 사망, 보상은 서버가 계산하고 클라이언트는 "여기로 이동", "이 대상 공격", "대화" 같은 의도만 보냅니다. 클라이언트를 조작해도 데미지를 바꿀 수 없습니다.
- **실행에 필요한 외부 패키지가 없습니다**: Node.js 22.13 이상만 있으면 됩니다. WebSocket은 직접 구현했고, 데이터베이스는 Node에 내장된 SQLite(`data/ravenmoor.db`)를 씁니다.
- **그래픽은 3D 모델을 구운 스프라이트**입니다: CC0 3D 모델을 Three.js로 8방향 × 5동작(대기·걷기·공격·피격·사망)으로 렌더링해 `assets/sprites`에 넣어 두었습니다.

## 실행

```bash
npm start          # http://localhost:8080
npm test           # 봇으로 계정·PK·상점·전리품·의뢰·은행·보스·승급까지 40개 항목 자동 테스트
```

처음 접속하면 **새 캐릭터** 탭에서 이름·비밀번호·외형을 정해 가입합니다. 브라우저 탭 두 개(또는 시크릿 창)로 다른 캐릭터를 만들면 같은 맵에서 서로 보이고, 채팅과 PK를 할 수 있습니다.

## 조작

| 입력 | 동작 |
|---|---|
| 땅 클릭 | 이동 |
| 몬스터·플레이어 클릭 | 쫓아가서 공격 (마을 안에서는 불가) |
| NPC 클릭 | 걸어가서 대화 (상점·대장간·여관·전직) |
| 바닥 아이템 클릭 / `Z` | 줍기 |
| `A` | 가장 가까운 몬스터 공격 |
| `H` / `S` / `D` | 치유 / 직업 기술 / 2차 기술 |
| `1` `2` `3` | 체력 물약 / 마나 물약 / 귀환 주문서 |
| `I` `E` `C` `Q` | 가방 / 장비 / 캐릭터 / 의뢰 창 (창은 제목줄을 끌어 옮김, 아이템은 두 번 눌러 사용·장착) |
| `M` | 소리 켜기/끄기 |
| `Esc` | 창 닫기 / 멈춤 |
| `Enter` | 대화 |
| 미니맵 클릭 · 마우스 휠 | 이동 · 확대/축소 |

## 지금 들어간 규칙

- **계정**: 이름 + 비밀번호(scrypt 해시) 로그인, 14일 유지되는 세션, 가입·로그인 시도 제한(IP당 5분 10회). 같은 계정으로 다른 곳에서 접속하면 이전 접속이 끊깁니다.
- **안전 지대와 PK**: 마을(성벽 안·성문)에서는 누구도 공격할 수 없고 몬스터도 못 들어옵니다. 성 밖에서 선량한 플레이어를 공격하면 1분간 보라색 이름, 죽이면 붉은 이름(카오틱). 카오틱은 죽을 때 금화 20%와 가방 속 아이템 하나를 바닥에 떨어뜨립니다. 예배당에서 헌금으로 속죄할 수 있습니다.
- **전리품**: 몬스터가 죽으면 금화와 아이템이 바닥에 떨어집니다. 처음 10초는 처치한 사람만 주울 수 있고, 2분 뒤 사라집니다.
- **아이템**: 무기 9종, 방어구·투구·방패·장화·장갑·반지, 물약, 귀환 주문서, 재료 4종(낡은 뼈·녹슨 철조각·저주받은 천·영혼석). 가방 36칸, 장비 7칸.
- **NPC**: 대장장이 로릭(무기 판매·제작·강화 +9까지, +4부터 실패 시 하락), 상인 베라(방어구·물약), 여관 주인 올가(휴식), 성문 경비병.
- **전직(레벨 10)**: 기사(기사단장 가웨인, 방패 강타·기절), 마법사(대마법사 이졸데, 원거리·화염구), 성직자(사제 안셀, 강화된 치유·신성한 빛), 도적(여관의 라스, 빠른 공격·급소 찌르기·출혈).
- **2차 전직(레벨 20)**: 같은 스승에게 승급. 팔라딘(신성 일격), 대마법사(번개 사슬), 주교(축복), 암살자(연속 찌르기). 두 번째 기술은 `D`.
- **보스 4종**: 회색 송곳니(남동쪽 강가, 울부짖어 졸개 소환·도약), 타락한 성기사(북동쪽 숲, 예고 후 내려찍기), 족장 크루쉬(북서쪽 야영지, 돌진·포효 기절), 리치 왕(남서쪽 늪, 내려찍기·소환·재생). 전용 장비를 떨어뜨리고 3~7분 뒤 다시 나타나며, 처치는 전체 공지됩니다.
- **의뢰 9종**: 경비병·상인·스승이 줍니다. 머리 위 `!`는 받을 수 있는 의뢰, `?`는 완료 보고. 토벌 수와 수집품은 서버가 셉니다.
- **은행**: 은행원 마르타에게 물건 48칸과 금화를 맡깁니다. 맡긴 것은 죽어도 잃지 않습니다.
- **밤낮**: 게임 하루는 실제 10분. 밤엔 플레이어·NPC·성문·우물 주변만 등불로 밝습니다. 시간은 서버가 정해 모두에게 같습니다.
- **소리**: 외부 파일 없이 코드로 합성한 효과음(타격·치명타·전리품·레벨업·기술·보스)과 바람·분수·밤 귀뚜라미·6시간마다 종소리. 거리에 따라 작아집니다.
- **몬스터**: 해골 졸개 Lv2 · 도적 Lv5 · 전사 Lv9 · 마법사 Lv13. 마을에서 멀어질수록 강해집니다.
- 모든 판정(이동·공격·구매·제작·강화·전직)은 서버가 하고, NPC와의 거리도 서버가 확인합니다.

## 폴더 구조

```
server/   index.js(웹 서버·계정 API)  ws.js(WebSocket)  db.js(SQLite)  game.js(게임 규칙·틱)
shared/   world.js(맵·길찾기)  rules.js(아이템·상점·직업)  ← 서버와 클라이언트가 함께 씀
client/   index.html  style.css  main.js(렌더링·입력·HUD)  ui.js(가방·장비·상점 창)
assets/sprites/   구운 스프라이트 PNG + manifest.json
tools/bake/       3D 모델 → 스프라이트 굽기 도구
tools/test-multiplayer.mjs   자동 테스트
```

## 스프라이트 다시 굽기 / 새 모델 추가

```bash
npm run fetch-assets                      # CC0 원본 모델 + Three.js 받기
npm i -D playwright && npx playwright install chromium
npm run bake                              # 전부
npm run bake -- knight castle             # 일부만
```

`tools/bake/config.json`에 모델 파일, 크기, 동작 이름을 적으면 됩니다. glTF/GLB 형식을 지원합니다.
